Build & flash

This keymap is a QMK userspace overlay — it needs a sibling qmk_firmware checkout and the qmk CLI. Build from the QMK MSYS terminal.

Compile — one build per half

# left half — TFT display module
qmk compile -kb splitkb/halcyon/kyria/rev4 -km isaacsa51 -e HLC_TFT_DISPLAY=1 -e TARGET=kyria_display

# right half — Cirque trackpad module
qmk compile -kb splitkb/halcyon/kyria/rev4 -km isaacsa51 -e HLC_CIRQUE_TRACKPAD=1 -e TARGET=kyria_cirque

TARGET only names the output .uf2. The module flag (HLC_TFT_DISPLAY / HLC_CIRQUE_TRACKPAD / HLC_ENCODER / HLC_NONE) is what selects the per-half build.

Flash — RP2040 UF2

  • 1Double-tap the reset button on a half → the RPI-RP2 drive mounts.
  • 2Drop the matching .uf2 onto it. The half reboots into the firmware.
  • 3Repeat for the other half with its .uf2.

Handedness is automatic (GP24 pin) — the same handedness build works on both sides. If a fresh build ignores the RGB defaults, reset EEPROM once: hold EE_CLR while plugging in, or flash then bootloader-reset.
