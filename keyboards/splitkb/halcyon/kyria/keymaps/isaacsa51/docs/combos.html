Symbol combos

An iconic cipher — chord a shape or a tone, get the symbol. Each bar joins the two keys you press; the symbol sits on the bar. Combos resolve against layer 0, so the same physical keys fire them on every base (letters shown are Colemak-DH). Window ≈ 30 ms; 80 ms for the 4-key gestures. Active only on the three base layers.
