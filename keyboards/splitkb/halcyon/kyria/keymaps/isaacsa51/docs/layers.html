The yellow thumb key on each overlay board is the one you hold (or toggled) to be on that layer.

Notes per layer

  • NavW‹ / W› = word left / right (OS-aware; tap SF* first to select by word). Left cluster = OS-aware DelLn / DelWrd / Bksp / Cut / Copy / Paste. SelW = getreuer select_word — tap to select, tap again to extend.
  • SymComplete symbol set — the fallback for anything the combos don't cover (& % ~ backtick).
  • FunctionRight-hand home row is plain modifiers, so you can hold Fn and stack mods. Adj jumps to Adjust.
  • AdjustAlpha / Cana / Crate set the default base; Game toggles the game layer. RGB row: RM_* — on a PaletteFx effect, Hue = palette selector.
  • WMEvery key clears held mods, taps FancyWM's Alt+Win chord, waits ~30 ms, taps one key. Hold Mov / Swp to move / swap instead of focus. Base = TO(_ALPHA) hard exit. D1–D9 follow the Nav numpad.
  • GamePlain QWERTY block — no mod-taps, tap dances, or combos fire mid-game.
  • MouseLeft hand = wheel, right hand = pointer, mirroring the Nav arrow inverted-T. LMB+RMB combo = middle click.
  • WM pickerHold ZXCD → pick with the right hand (numpad order); hold H,./ → pick with the left. Tap the picking hand's inner-thumb one-shot Shift first → move the window there instead of switching.
