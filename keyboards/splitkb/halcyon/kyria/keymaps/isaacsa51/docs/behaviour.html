Home-row mods

Order pinky→index is Alt · GUI · Shift · Ctrl, mirrored on the right hand, on all three base layers.

Chordal Hold: an opposite-hand chord resolves as hold instantly; a same-hand roll stays a tap. TAPPING_TERM (200 ms) is only the fallback for a same-hand hold — tune 170–220, drop PERMISSIVE_HOLD if same-hand rolls misfire. The index-inner keys (G left, M right) have no mod.

Tap dances & thumb mods

Tap dances

  • Cmd / ~tap+hold → ⌘ (mac) / Ctrl (win) · double-tap → arm the smart tilde (left home outer)
  • Capstap → Caps Lock · double-tap → Caps Word — both flash the board red ×3 (left upper thumb)

Thumb mods — OS_SFT / OS_CTL

  • SF* / CT*Tap → one-shot Shift / Ctrl (the two stack). Hold → real Shift / Ctrl that engages the instant another key is pressed and holds until release — no tapping-term wait (Nav right thumb).
  • ⌥¹ / ⇧¹Plain one-shot Alt / Shift (OSM) on the base upper thumbs — always a one-shot.

Holding SF* + typing shifts everything; holding it + the arrows selects by word.

Smart tilde

The ~ key (right home outer) or a double-tap of Cmd / ~ arms a one-shot dead key. The next key decides:

Next keyOutput
a e i o uá é í ó ú
nñ   (the only path that branches on OS)
s l m d r t cstraight ' + that letter   (McDonald's, I'll, c'mon)
spacea lone '
anything elsethe tilde is dropped; the key types normally

Assumes a US-International host layout. A modifier pressed between ~ and the target passes through (so ~ → Shift → vowel = an uppercase accent). The latch also expires after ~1 s.

RGB

PaletteFx (getreuer/palettefx). Default Reactive effect + Polarized palette, re-forced with *_noeeprom on every plug-in by keyboard_post_init_user() — the EEPROM otherwise keeps a stale mode. Cycle at runtime with the RGB row on Adjust (RM_NEXT/PREV = effect, RM_HUEU/HUED = palette).

Other declarations

  • TG_OSFlip the OS mode Win ⇄ Mac (base bottom-right). Persists across replug/reboot.
  • SelWgetreuer/select_word — tap selects the current word, tap again extends by word (Nav).
  • MEH / HYPERCtrl+Shift+Alt / +GUI — app-specific shortcuts via Kanata etc. (base right thumbs).
  • MouseMO(_MOUSE); kinetic-curve cursor (MK_KINETIC_SPEED, base 6000 px/s — ramps up while held). LMB+RMB combo = middle click.
  • WM chordEvery WM key clears held mods, taps Alt+Win, waits ~30 ms, taps one key. Set FancyWM's activation hotkey to Alt+Win to match.
  • EscapesTO(_ALPHA) = Base on the WM layer (hard exit). Tap Nav / Sym / Fn / WM to toggle-lock a layer, hold for momentary.
